# Dynamic Business Intelligence Dashboard

## Overview

End-to-end Business Intelligence project built using
Python, Pandas, MySQL, SQL, Power BI, Plotly and Streamlit.

The application analyzes Superstore retail sales data
to uncover trends, profitability drivers, product
performance and regional business insights.

## Features

- Interactive KPI Dashboard
- Sales & Profit Trend Analysis
- Product Performance Analysis
- Regional Performance Analysis
- Business Insights & Recommendations
- Dynamic Filtering

## Technology Stack

- Python
- Pandas
- MySQL
- SQLAlchemy
- SQL
- Power BI
- Plotly
- Streamlit

## Analytics Pipeline

Raw CSV Dataset
↓
Pandas Data Cleaning
↓
MySQL Database
↓
SQL Analytics
↓
Power BI Dashboard
↓
Streamlit Web Application

## Dashboard Pages

- Home

## Key Business Insights

- Technology is the highest-performing category
- West region generates the highest sales and profit
- California and New York are top-performing states
- Q4 is the strongest sales period
- Several products require portfolio optimization
